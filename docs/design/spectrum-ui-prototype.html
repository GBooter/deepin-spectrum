峰值滑块 · 悬浮缓落

          PEAK SLIDER
          新选项
        

        
声音一冲上来，柱顶的小滑块被顶飞，短暂悬停后与柱体分离、缓慢落回。它不是从零做：项目里已有 peaks[] + peak_hold_ms 通道，这里把回落曲线参数化并交给你调。

配色约定：渲染器按画布的绝对高度插值——画布底部 = 柱底颜色，画布顶部 = 柱顶颜色。安静时你看到的多半是柱底色，只有大音量的高柱才会把柱顶色带出来。所以每套预置都把主色放在柱底、高潮色放在柱顶。

    


    
    

      

        03
        
动态

        MOTION / LIVE REBUILD
      

      
决定频谱「怎么跳」。起音快、衰减快的方案脆；两者都慢的方案像呼吸。改动会重建分析器，但在同一帧内完成，不中断采集。

      

      
避开 2048 档：项目 F56 已实证该档会让低频段塌缩，柱子变少且低频混在一起。本设计里所有预置只用 4096（均衡）或 8192（更细腻的低频）。
